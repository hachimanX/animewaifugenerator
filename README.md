# ✨ Anime Waifu Generator

**🌐 Live site: [animewaifugenerator.com](https://animewaifugenerator.com/)**

A free, instant anime character generator. Pick a category, hit **Generate Waifu**, and get a random anime image — no sign-up, no install, works on desktop and mobile.

## What it does

- 🎲 Generates random anime images across **60+ categories** — Waifu, Neko, Husbando, Kitsune, plus animated reaction GIFs (hug, pat, smug, dance, and more)
- ⚡ Instant results, one click per image
- 📤 Share button to send your favorite results to friends
- 🎨 Artist credit shown for every image, with a link to the original source

## How it works

A static site built with plain **HTML, CSS, and JavaScript** — no frameworks, no build step. Images come from the free [nekos.best](https://nekos.best) API.

> Note: the site previously used the waifu.pics API, which has shut down. It now runs on nekos.best.

## Running locally

```bash
git clone https://github.com/hachimanX/animewaifugenerator.git
cd animewaifugenerator
# open index.html in your browser — that's it
```
